# حصر حديد التسليح — أدوات ومهارات (Rebar Takeoff & Cutting)

أدوات بايثون ومهارات Claude Code لحصر حديد التسليح من لوحات الأوتوكاد الإنشائية (DWG/DXF)،
وتفريد الحديد (تحسين قطع الأسياخ). بُنيت على أعراف لوحات استشارية حقيقية.

> **ملاحظة سرّية:** هذا المستودع يحوي **الأدوات فقط**. لوحات العميل (DWG/DXF) ومخرجات الحصر (Excel)
> مُستبعَدة عبر `.gitignore` ولا تُرفع.

## المحتوى

| المجلد / الملف | الوصف |
|---|---|
| `scripts/` | محرّكات بايثون: `takeoff.py` (الإضافي)، `slab_mesh.py` (الفرش والغطاء)، `full_takeoff.py` (حصر كامل)، `cutlist.py` (التفريد)، `ceiling_takeoff.py` |
| `skill-build/rebar-takeoff/` | مهارة **rebar-takeoff**: SKILL.md + references + scripts |
| `skill-build/rebar-cutting/` | مهارة **rebar-cutting** (تفريد الحديد): SKILL.md + references + scripts |
| `*.skill` | المهارات المحزومة جاهزة للتثبيت |

## المهارتان

1. **rebar-takeoff** — حصر الحديد من لوحة تسليح:
   - التسليح الإضافي (علوي/سفلي): يعدّ الأسياخ من الكولّات `T16-200-T` إلخ.
   - الفرش والغطاء (الشبكة الرئيسية): بمنهج المساحة + وصلات التراكب الحقيقية.
   - يُخرج إكسل منظّم + لوحة مراجعة بدوائر مرقّمة + ملف `pieces.json`.
2. **rebar-cutting** — تفريد الحديد (cutting-stock): يأخذ قائمة القطعيات ويقطعها من أسياخ 12م
   بمنهج «التتالي حسب المقاس» (الأكبر أولاً، والمتبقّي يُقطع لأقرب مقاس أصغر = أقل هدر).

## المتطلّبات

- **Python 3** مع `ezdxf` و `openpyxl`:
  ```bash
  python -m pip install ezdxf openpyxl
  ```
- **ODA File Converter** (اختياري): لتحويل DWG ⇄ DXF فقط.

## الاستخدام السريع

```bash
# حصر كامل لسقف (إضافي + فرش وغطاء) + تفريد + لوحة مراجعة
python scripts/full_takeoff.py "LOWER BASEMENT CEILING" --dxf "<ملف اللوحة.dxf>" --cut --dwg

# تفريد قائمة قطعيات (من مخرجات التكوف)
python scripts/cutlist.py "<ملف pieces.json>"
```

> المسارات الافتراضية داخل `scripts/takeoff.py` مثبّتة على جهاز التطوير — عدّلها أو مرّر `--dxf` و`--outdir`.

## الأعراف (مهم)

المهارات مبنيّة على أعراف مكتب استشاري محدّد (طبقات `ST-RFT-*`، الفتحات على `S - dot`،
صيغة الكولّات `T##-###-T|B`، ملاحظات الشبكة كـ block attributes). قد تحتاج ضبطاً للوحات
بأعراف مختلفة.
