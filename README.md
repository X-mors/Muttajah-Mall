# حصر الكميات الإنشائية — أدوات ومهارات (Structural Quantity Takeoff)

أدوات بايثون ومهارات Claude Code لحصر الكميات من لوحات الأوتوكاد الإنشائية (DWG/DXF): حديد التسليح،
تفريد الحديد، عدّ الأعمدة، وحصر خرسانة الأعمدة. بُنيت على أعراف لوحات استشارية حقيقية (مشروع Muttajah Mall).

> ⚠️ **مهم — نطاق العمل:** هذه المهارات مُعايَرة على **أعراف لوحات هذا المكتب الاستشاري تحديداً**
> (مشروع Muttajah Mall): أسماء الطبقات، صِيَغ الكولّات والملاحظات، ترميز المناسيب (S.S.L) والهوابط
> (drop panel) وجدول الأعمدة. **قد لا تعمل كما هي على مشاريع أو مكاتب أخرى بأعراف مختلفة** وتحتاج
> ضبطاً للطبقات/الصِّيَغ. الاستثناء: `rebar-cutting` مُحسِّن قطعٍ عام (يأخذ قائمة قطعيات، لا يقرأ لوحة).

> **ملاحظة:** يحوي المستودع **الأدوات والمهارات**، إضافةً إلى **لوحة مرجعية واحدة** في `drawings/`
> صرّح صاحب المشروع بنشرها. بقية لوحات العميل ومخرجات الحصر (Excel) مُستبعَدة عبر `.gitignore`.

## المهارات

| المهارة | الوصف |
|---|---|
| **rebar-takeoff** | حصر حديد التسليح: الإضافي (كولّات `T16-200-T`) + الفرش والغطاء (منهج المساحة + وصلات التراكب). إكسل + لوحة مراجعة مرقّمة + `pieces.json`. |
| **rebar-cutting** | تفريد الحديد (cutting-stock) بمنهج «التتالي حسب المقاس» (الأكبر أولاً، والمتبقّي يُقطع لأقرب مقاس أصغر = أقل هدر). |
| **columns-takeoff** | عدّ الأعمدة من لوحة COLUMNS & AXES + جدول الأعمدة (العدد + المقطع + التسليح لكل ماركة). |
| **concrete-takeoff** | حصر خرسانة الأعمدة (م³): لكل عمود = طول×عرض×ارتفاع صافٍ، بمقطع كل مرحلة من الجدول، ولوحة مراجعة بدوائر مرقّمة تطابق الإكسل. |

## المحتوى

| المجلد | الوصف |
|---|---|
| `scripts/` | محرّكات بايثون: `takeoff.py`، `slab_mesh.py`، `full_takeoff.py`، `cutlist.py`، `ceiling_takeoff.py`، `columns_takeoff.py`، `concrete_columns_takeoff.py` |
| `skill-build/<skill>/` | مصدر كل مهارة: `SKILL.md` + `references/` + `scripts/` |

| `*.skill` | المهارات المحزومة جاهزة للتثبيت |

## المتطلّبات

```bash
python -m pip install ezdxf openpyxl
```
- **ODA File Converter** لتحويل DWG ⇄ DXF (الأسماء غير اللاتينية تُنسخ لاسم ASCII مؤقّت أولاً).

## الاستخدام السريع

```bash
# حصر حديد كامل لسقف (إضافي + فرش وغطاء) + تفريد + لوحة مراجعة
python scripts/full_takeoff.py "LOWER BASEMENT CEILING" --dxf "<ملف.dxf>" --cut --dwg

# تفريد قائمة قطعيات
python scripts/cutlist.py "<pieces.json>"

# عدّ الأعمدة (العدد + المقطع لكل ماركة)
python scripts/columns_takeoff.py --dxf "<ملف.dxf>"

# حصر خرسانة أعمدة دور (مرحلة) — إكسل لكل عمود + لوحة مرقّمة؛ الارتفاع تلقائي من المناسيب
python scripts/concrete_columns_takeoff.py --stage 2 --dwg
```

> **محمول:** المسارات الافتراضية نسبيّة للمستودع — تُحمَّل اللوحة تلقائياً من `drawings/` ويُكتشَف ODA بأي
> إصدار، فيعمل بعد الاستنساخ مباشرةً. مرّر `--dxf "<ملف>"` لأي لوحة أخرى.

## حصر خرسانة الأعمدة — القاعدة

ارتفاع العمود = من سقف الدور الأسفل إلى سقف الدور (سقف↔سقف) ناقص سُمك ما يعلوه: **بلاطة ٢٢سم** أو
**drop panel ٣٢سم**. المناسيب (S.S.L) قد تتعدّد داخل الدور الواحد (بلاطة مُدرَّجة) فالارتفاع يُؤخذ لكل
عمود من أقرب منسوب. التفاصيل في `skill-build/concrete-takeoff/references/concrete-method.md`.

## الأعراف (مهم)

المهارات مبنيّة على أعراف مكتب استشاري محدّد (طبقات `ST-RFT-*`/`ST-203-SLAB-TXT`/`ST-TEXT`، الفتحات على
`S - dot`، كولّات `T##-###-T|B`، ملاحظات/مناسيب كـ block attributes، `SLAB=###mm`، هوابط `320` على
`S-TEXT`). قد تحتاج ضبطاً للوحات بأعراف مختلفة.
